# Retired archive artwork bucket

Existing migration 20370601100000 and the Gaycities scraper's DEAD_IMAGE_HOSTS contract already document and remove the retired featured-images S3 bucket. Missing-artwork findings still reappear because the source outcome was not recorded. Approximately 3,300 completed legacy archive records retain that pointer in their registered capture.

This extends the existing historical-source workflow only when each registered record identifies the same event, date, source ID and single retired-bucket artwork URL. Every alternative image, current image, human image edit, reviewer decision, ambiguous source, nonarchive record and unknown ownership remains protected. Each eligible URL must have an individually captured HTTP 403 application/xml AccessDenied response, fresh at registration and with a matching response hash. Transport failures and generic 403 responses do not qualify. Canonical event/source rows remain byte-for-byte unchanged.

The default-dry collector makes public anonymous requests only to the fixed retired bucket, follows no redirects and bounds each response to 8 KiB. The registration operator validates response XML, hashes, capture time, source snapshots and ownership under native row locks before inserting a failed source observation and invoking the existing source-outcome workflow. It never declares an image passed. Missing media still scores zero. A later successful observation or newly supplied source poster invalidates the unavailable outcome and reopens recovery.

Validation: the existing 30 Graph ownership/source cases still pass, plus 25 retired-bucket cases, normal-producer re-scan, unchanged full event rows, and six registration cases covering a correct capture, bad hash, stale response, changed source, different XML error and protected human media. The registration test applies exactly one real source outcome and leaves all five invalid/protected cases untouched. Disposable PostgreSQL only; native rollout is journaled separately after normal migration deployment.
