# Prevent unsupported API discoveries from entering review

Foursquare API searches returned generic hotels and bars for LGBTQ search phrases. Search ranking does not establish relevance. Unlike the existing snapshot path, the API path staged every new identity and required independent editorial review even when its own normalized discovery evidence was empty.

New API discoveries now require an explicit relevance signal in the provider's name, description, website, Instagram, category or tastes. Search terms, broad hotel/bar taxonomy, rainbow/pride alone and the automatic review flag do not establish eligibility. Known canonical identities retain source/contact updates. Evidence-backed discoveries retain the independent review gate; this change does not authorize publication.

Three focused tests cover generic search pollution, positive explicit evidence and canonical enrichment. Entry-point type checking and scoped lint pass. The same pure filter was selectively installed into both fresh remote bundles: source-foursquare v1855 and source-foursquare-free v9. The free-tier runtime's current API, OS snapshot/delta processing, budget reservation, authentication and editorial protections were preserved. The legacy repository entrypoint received the equivalent permanent filter and bounded canonical identity lookup. The standalone free wrapper is not currently represented in the repository; its existing remote modules were preserved rather than replaced by the legacy entrypoint.

The default-dry cleanup operator checks untouched pending Foursquare venue staging records with no canonical source/venue link and no explicit provider relevance. It rechecks complete snapshots under row locks and protects human decisions and unrelated review types. It retains every raw/normalized source field, records a truthful automatic rejection reason, and rejects only the corresponding untouched automatic corroboration task. It never creates, publishes or changes a venue or business finding. Fresh atomic journals precede writes; unknown writes are not retried. A 20-record production rollback passed the whole-row preservation assertion.

Native rollout receipts: outputs/foursquare-unsupported-preview-20261024.json, outputs/foursquare-unsupported-rollback-20261024.json and outputs/foursquare-unsupported-apply-20261024.json. The initial preview found 1,705 unsupported automatic discoveries and preserved all 28 evidence-backed records.
